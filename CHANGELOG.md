# Changelog / История изменений

## Что нового в 1.17.0
- Новости и список серверов с пингом на главной, кнопка «Зайти»
- Статистика игры (часы по дням и серверам)
- Поделиться сборкой: код или файл .farmpack, импорт «От друга»
- Проверка и обновление модов одной кнопкой
- Discord: вход/выход с сервера, скрин по клавише
- Метки (waypoints) для друзей по LAN
- Профили модулей для каждого сервера, раскладки HUD (Ctrl+C/V, слоты 1-3)
- Сайт на GitHub Pages (папка docs)

## Что нового в 1.16.1

- Встроенный вебхук Discord: скриншоты, краш-репорты и «Открыл мир» уходят в канал Farm Client без настройки (свой вебхук можно вписать в Настройки → Скины и Discord).

## Что нового в 1.16.0

- Настройки лаунчера стоят плотно, без пустых мест между карточками.
- CurseForge рядом с Modrinth: моды, ресурспаки, шейдеры и сборки (переключатель Modrinth / CurseForge). Сборки CurseForge (.zip) можно ставить и из файла. Свой ключ API — Настройки → Лаунчер.
- Discord: показывает, где ты — «Одиночная игра», «Сервер: адрес» или «В главном меню» (LAN/VPN-адреса скрыты; адрес можно выключить).
- Мод 1.31.0: отдельная вкладка «Метки» (Waypoints), модуль «Вкладки» в Настройках — скрывай ненужные вкладки; Obsidian Miner плавнее: учёт пинга, запасные блоки из хотбара, возврат слота, стоп при уроне/у лавы, предупреждение о прочности кирки, плавный HUD.

## Что нового в 1.15.0

## Что нового в 1.14.0

- Исправлен краш (StackOverflowError) на SpookyTime/FunTime: Combat Timer реагировал на своё же сообщение «Режим боя» и зацикливался. Все модули, читающие чат, теперь игнорируют сообщения самого клиента.
- «“Кактус”»: новая настройка «Только от кактуса» (включена по умолчанию) — картинка и звук только при смерти об кактус.
- Новый модуль «Crystal PvP» (Визуал): крупное «ТОТЕМ СГОРЕЛ! осталось N» при своём попе, звук попа врага, заряды якоря под прицелом, счётчик кристаллов рядом, предупреждение «мало тотемов», размер/скорость вращения/подпрыгивание кристаллов (1.21.4+). Только визуал — ничего не делает за игрока.
- Лаунчер: «дизайнерская» полировка — плавные переходы страниц с каскадом блоков, пружинные модалки и переключатели, рябь на кнопках, блик на «Играть», блик на прогрессе, аккуратные скроллбары; синтезированные звуки интерфейса (клик, наведение, вкл/выкл, открытие/закрытие, успех/ошибка, запуск). Настройки → Обновления: «Звуки интерфейса», «Звук наведения», громкость, «Анимации».
- Лаунчер: свои выпадающие списки (анимация, поиск стрелками, галочка у выбранного), ползунки с заливкой, красивые подсказки вместо системных, свои окна подтверждения (красные — для удаления), плавное появление окна. Работает во всех темах.
- Сборки: предустановлены оптимизационные моды Lithium, FerriteCore, ModernFix, ImmediatelyFast, Krypton, BadOptimizations и Dynamic FPS (без Iris). В уже созданные сборки доставятся один раз при следующем запуске.

## Что нового в 1.12.0
- Тема **Минимализм** (лаунчер и мод): ровные полупрозрачные панели, тонкие линии, без свечения; настраиваются акцент, фон, панели, текст, плотность, размытие, скругление + готовые пресеты.
- «Сеть»: блок **«Люди в сети»** — все, кто с тобой в одной сети Radmin VPN (по ARP), и лаунчеры Farm Client с ником и их открытыми мирами; кнопка «Добавить» в друзья. Сеть работает в фоне.

- Новая заставка установщика «Подождите, пожалуйста…».

- Мод FARM CLIENT 1.21.0: порт на 1.16.5 — ClickGUI, HUD и редактор, главное меню, кулдауны, Target HUD, Fullbright/Gamma, No Fog, No Render, Zoom/Freelook/Freecam, анимации взмаха, ESP, чат-твики и др.
- Не перенесены на 1.16.5 (нет API в старой версии): Enchant Glow, Item Physics, Auction Helper, Shulker Preview, Sky Changer, размытие фона меню, Wind Charge. *(В 1.4.8 почти всё перенесено — см. выше.)*

## Что нового в 1.4.6
- **Багфикс запуска:** если Java не стартовала (антивирус, битый путь), лаунчер больше не залипает в «Игра уже запускается».
- **Стандартные моды не блокируют игру:** если какой-то мод не найден на Modrinth для версии (например 26.3) или нет интернета — он пропускается, игра запускается, а установка повторяется позже автоматически.
- **Обновления мода:** скачанный апдейт Farm Client больше не перекрывает более новую версию, встроенную в лаунчер.
- **Microsoft без интернета:** при временной ошибке сети используется сохранённая сессия вместо отказа в запуске; в `launcher_version` передаётся реальная версия лаунчера.
- **Окно краша:** подсказка причины простыми словами (память, Java, конфликт модов, Mixin, драйвер), кнопки «Копировать» и «Показать лог / краш-репорт».
- Мод FARM CLIENT 1.20.5: **исправлен краш 26.3 при запуске игры**, защита от крашей модулей, новый модуль **Low HP Vignette**.

## Что нового в 1.4.5
- Мод FARM CLIENT 1.20.4 — Mini Player: обложка берётся из того же источника, что и плеер Windows возле Wi-Fi/Bluetooth (SMTC), тремя способами чтения; PowerShell сам делает PNG 64×64, игре не нужен AWT. Диагностика: `%TEMP%\farmclient-media.log`.
- Длинные название и исполнитель листаются бегущей строкой — видно весь текст (и в компактном стиле).

## Что нового в 1.4.4
- Мод FARM CLIENT 1.20.3: новый набор звуков меню **«Серьёзный»** (глубокое «войлочное» пианино и глухие низкие щелчки); наборы меню (Кристалл / Мягкий / Серьёзный / Пузыри) доступны и как **звуки клавиш** WASD, пробела, ЛКМ и ПКМ (Keystrokes → «Звук клавиш»).
- Mini Player: обложка трека читается надёжнее (DataReader вместо AsStreamForRead в Windows PowerShell 5.1) и догружается, если плеер отдал её с опозданием.

## Что нового в 1.4.3
- Мод FARM CLIENT 1.20.2: **звуки меню** (наведение, клик, вкл/выкл, ползунки, режимы, бинды, ввод, сброс, открытие/закрытие; наборы Кристалл / Мягкий / Пузыри — Кастом → Звуки меню), **сброс настроек модуля** («↺ Сбросить настройки» внизу окна настроек), логотип-картинка в меню, Watermark и главном меню мода.
- Ярлыки на рабочем столе/в Пуске и «Приложения» Windows берут иконку из `resources/icon.ico` — значок отображается, даже если кэш иконок Windows старый.

## Что нового в 1.4.2
- Каталог Modrinth: вкладки **Ресурспаки** и **Шейдеры** (кнопки на странице «Моды»). Ресурспаки → `resourcepacks/`, шейдеры → `shaderpacks/`; для шейдеров на Fabric/Quilt автоматически ставится Iris.
- В обычном главном меню вместо «ely.by» — подпись «Farm Client» (`--versionType`, `-Dauthlibinjector.noShowServerName`).
- Мод FARM CLIENT 1.20.1: обложка трека/превью видео в Mini Player, Chat Shift (HUD уезжает вверх при открытом чате), убрана кнопка быстрого входа на сервер в своём меню.

## Что нового в 1.4.1
- **Сборки Modrinth**: «Версии» → «Сборки Modrinth» — поиск модпаков, выбор версии сборки, установка в отдельную папку (моды, конфиги, ресурспаки из overrides). Кнопка «Из файла» ставит локальный `.mrpack`.
- **Версия загрузчика**: у каждой своей сборки — кнопка-шестерёнка для смены версии Fabric/Quilt/Forge/NeoForge; у версий Farm Client можно выбрать конкретный Fabric Loader (по умолчанию — последний стабильный).
