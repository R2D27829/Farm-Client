FAQ

Which Minecraft versions?

The Farm Client mod supports 1.16.5, 1.21.4, 1.21.11 and 26.x (Fabric). The launcher can install any vanilla, Fabric, Quilt, Forge or NeoForge version.

Windows SmartScreen warning

The launcher isn't signed with a paid certificate. Click “More info” → “Run anyway”.

Linux

chmod +x FarmClient-*.AppImage and run it. If it doesn't start, install libfuse2.

Is it free?

The launcher and basic modules are free. A license unlocks extra modules; there's a free 3-day trial once per device.

Is it a cheat client?

No. Only QoL, visuals and performance — safe for servers.
