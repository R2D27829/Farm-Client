Версия Minecraft.
Подходящая Java.

Установка версии Minecraft в лаунчере и поддержка Farm-мода — не одно и то же. Ниже — четыре порта Farm-мода из релиза 1.38.0.

MinecraftFarm-модJava
1.16.5Fabric17
1.21.4Fabric21
1.21.11Fabric21
26.3Fabric25

Требования относятся к портам Farm-мода 1.38.0, а не ко всем возможным ванильным сборкам.

Что делать перед запуском

  1. Сверь версию Minecraft с сервером или миром друга.
  2. Выбери нужный загрузчик и совместимые версии модов.
  3. Проверь Java в настройках профиля.
  4. Сохрани резервную копию мира перед переходом между версиями.

Ограничения, о которых важно знать

Наличие Legacy-лаунчера для старой Windows не делает Java 21 или 25 совместимой с этой ОС. ARM64-пакет лаунчера не гарантирует наличие нативных библиотек для каждого стороннего мода.

Релиз прошёл проверки сборки и содержимого пакетов, но не полный игровой прогон на всех физических устройствах и не двухпользовательское тестирование. Возможны конфликты с другими модами.
