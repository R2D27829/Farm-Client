Все версии Farm Client

Актуальные и архивные выпуски для каждой системы. Выбирай нужную архитектуру; предварительные сборки отмечены отдельно.

Новый Farm Client 1.37.0 Preview: установщики Windows EXE с выбором папки и ярлыками, macOS DMG с переносом в «Программы». ZIP — только портативный вариант. Доступные платформы: Windows x64/ARM64, Legacy x64/x86, Linux x64/ARM64, macOS Intel/Apple Silicon и Android. Включите «Показывать предварительные», чтобы увидеть файлы. Android Preview устанавливается отдельно и не обновляет прежний APK: не удаляйте старое приложение и миры. macOS — без подписи и нотариализации. Legacy использует устаревший Electron; совместимость с новым Minecraft на Windows 7/8/8.1 не гарантируется. Косметика пока локальная.
