FARM / РУКОВОДСТВО 01

Установка без путаницы.
Обновление без удаления миров.

Версия выпуска — 1.38.0. На Windows установка с нуля и обновление — разные пакеты. Выбери свой сценарий, прежде чем скачивать EXE.

Открыть загрузкиОписание релиза ↗
01

Новый Windows-ПК

  1. На странице загрузок найди базу 1.37.1.
  2. Выбери архитектуру и ветку Modern / Legacy, установи и запусти клиент.
  3. Закрой клиент. Запусти EXE 1.38.0 той же архитектуры и ветки в прежней папке.

EXE 1.38.0 сам по себе не выполняет установку с нуля.

02

Клиент уже установлен

  1. Сделай резервную копию важных миров и пользовательских настроек.
  2. Закрой Farm Client и выбери обновление 1.38.0 своего профиля.
  3. Укажи прежнюю папку установки. Не удаляй пользовательский каталог.

Пакет обновляет файлы в существующей папке и не создаёт новые ярлыки.

Как выбрать архитектуру

  • Windows x64: современные 64-битные Intel / AMD.
  • Windows ARM64: Windows-устройства на ARM; не выбирай по размеру файла.
  • Legacy x64 / x86: отдельная устаревшая ветка для старых ОС. Это не гарантия поддержки нового Minecraft.
  • macOS: x64 для Intel, ARM64 для Apple Silicon. Linux: выбирай архитектуру процессора.

Linux

Скачай AppImage 1.38.0 под свою архитектуру. Разреши запуск: chmod +x FarmClient-*.AppImage. Замени прежний файл, не удаляя пользовательский каталог.

macOS

Открой DMG 1.38.0 и замени приложение в «Программах». Подпись ad-hoc, нотариализации Apple нет. Не отключай защиту системы целиком.

Android

APK 1.38.0 обновляет совместимую установку 1.37.1 с ID com.farmclient.launcher и тем же ключом подписи. Ранние APK с другим ID или подписью автоматически не мигрируют — не удаляй их и миры ради обновления.

Проверка файла и первый запуск

Скачивай из официального репозитория. SHA-256 опубликованы в описании релиза. Windows EXE не имеет сертификата доверенного издателя: предупреждение системы само по себе не доказывает безопасность файла. Сверь источник и хеш; не выключай защиту целиком.

После запуска проверь аккаунт, каталог игры и Java для выбранной версии. Ключ Farm Client вводится в Настройки → Лицензия; покупать его для установки самого бесплатного лаунчера не нужно.
